# CNC Press Coolant System

The CNC press coolant loop removes heat from the spindle and cutting zone. Operators should check coolant level, flow, filter condition, and pump noise at the start of each shift.

## Warning signs

- A rising pump vibration or intermittent flow can indicate a worn seal or bearing.
- High spindle temperature can cause dimensional variation and unplanned machine stops.
- Stop the press if coolant flow falls below the marked minimum. Notify maintenance and record the time and affected work order.

## Recovery

Maintenance should isolate power, inspect the pump and seals, replace damaged parts, restore coolant flow, and verify temperature stability before returning the machine to production.
